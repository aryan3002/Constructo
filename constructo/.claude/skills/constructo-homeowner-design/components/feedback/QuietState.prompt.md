**QuietState** — the calm empty/quiet state. Success is *earned absence*, not engagement.

```jsx
<QuietState
  icon="sun"
  title="All calm"
  message="Nothing needs you today. We'll tell you the moment it does."
/>
<QuietState tone="quiet" icon="clock" title="Site quiet" message="Curing — normal. Nothing to worry about." />
```

Never an error tone, never red, never a streak/nudge. Pass one gentle `action` only if truly needed.
