# Superseded homeowner design artifacts

`homeowner-DESIGN.md` was the **first** homeowner visual system ("Calm Cockpit", teal/cream),
authored for Google Stitch. It is **superseded** by the locked **Direction C** system, which now
lives as a real Claude Code skill:

    constructo/.claude/skills/constructo-homeowner-design/   (SKILL.md + readme.md + styles.css + tokens + fonts + components + ui_kits)

For any homeowner UI work, use the **`constructo-homeowner-design`** skill — it is the single
source of truth for the homeowner visual language. Kept here for history only.

The sibling docs in `docs/design/` (`homeowner-stitch-prompt-library.md`, `homeowner-design-handoff.md`,
`homeowner-screen-plan.md`) still describe the **screen set / IA / states**, which remain valid — but
their *visual* token/colour details are superseded by the skill above.
